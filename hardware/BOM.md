## 二、整机模块、电源与连接配件

以下按一套设备列出；这些模块、电源及配件不属于上表的 22 个 PCB 板级位号。随模块附带的天线、线束等不必重复采购。

| 物料 | 数量 | 型号或说明 |
| --- | ---: | --- |
| 气象站 PCB 裸板 | 1 | 使用本目录的硬件工程制作；板级焊接器件见上表 |
| STM32 开发板 | 1 | STM32F103C8T6 最小系统板 |
| 温湿度模块 | 1 | DHT11，单总线 |
| 气压模块 | 1 | BMP280，I²C；设备曾读取到芯片 ID 0x58 |
| 光照模块 | 1 | 光敏电阻式模块，使用 AO 模拟输出；模块和芯片具体型号待确认 |
| 粉尘模块 | 1 | GP2Y1010 系列；此前提供型号 GP2Y1010AU0F，完整实物丝印待核对 |
| OLED 显示模块 | 1 | I²C OLED；程序按 128×64 配置，面板尺寸和控制器型号待确认 |
| 4G 通信模块 | 1 | 合宙 Air780E-B AT 版，转接板丝印 VIN / GND / RXD / TXD / DTR / RST / RDY |
| 风速传感器 | 1 | 聚碳三杯式风力测量仪；具体型号、量程、供电和输出信号待核对；当前 FreeRTOS 固件尚未实现风速采集 |
| 开关电源适配器 | 1 | 12V 1A；直流插头规格、极性及负载能力以实物为准 |
| 直流降压模块 | 1 | MINI560，项目使用 12V 转 5V；用户提供的标称输出为 5V 5A。两种称呼指同一块模块，不重复计数 |
| 4G 天线及配套射频线 | 1 套 | 根据转接板实际接口选择；若模块已附带则无需重复购买 |
| 4G 物联网 SIM 卡 | 1 | 需具备可用的移动网络服务；运营商及资费按实际选择 |

| 传感器及供电连接线 | 1 套 | 按粉尘、风速及电源接口的实际插头和线序配备；随模块附带的线束不重复采购 |

风速硬件已列入清单，但当前 FreeRTOS 项目暂未实现风速采集、显示、上传和风速报警；旧版参考代码位于仓库的 `legacy/wind_sensor/`。

**供电能力：** MINI560 的 5A 是用户提供的模块标称值，并不代表本项目使用 12V 1A 适配器时可以输出 5V 5A：适配器标称功率约 12W，而 5V 5A 为 25W。转换损耗和其他负载会进一步影响可用功率，整机供电余量需按实际负载核对。

## 四、使用说明

- [本地 EDA 原工程](weather-station.epro) 与 [原理图 PDF](schematic.pdf) 为原工程资料；采购及焊接前应核对实际板卡、封装、电压和模块引脚。
- PCB 板级原始 BOM 导出自已打开的 PCB 页面，22 个位号、数量、标称值、封装和料号已与本地 EDA PCB 数据比对一致；这不等于实物、原理图、供货信息均已验证。
- PM2.5 目前使用旧公式计算，属于未标定的粉尘估算值；光照输出是相对百分比，不代表经过标定的 lux。
